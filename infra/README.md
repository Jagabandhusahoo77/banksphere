# Infra

Infrastructure and platform configuration for BankSphere, covering AWS provisioning, Kubernetes resource definitions, and Helm packaging.

## Structure

```text
infra/
├── terraform/    AWS infrastructure as code
├── kubernetes/   Raw Kubernetes manifests
└── helm/         Helm chart(s) for packaging the application
```

See the README in each subdirectory for details. No AWS resources have been provisioned yet.
